Third-party components
======================

This program is distributed as a single executable that statically links the
following Rust crates (see `vendor/` and `Cargo.lock` for the exact versions and
their license files).

- egui, epaint, ecolor, emath, egui-winit, egui_glow, eframe
- egui_extras (not used any more, may remain in the lock file)
- winit, glutin, glutin-winit, glow, arboard, webbrowser
- rfd (rusty file dialog)
- rodio 0.17.3, cpal
- zip 0.6.6, flate2, miniz_oxide
- image 0.25, png, jpeg-decoder, zune-jpeg
- bytemuck, ahash, hashbrown, ...

Windows system libraries
------------------------
The executable calls Windows APIs (WASAPI, user32, gdi32, dwmapi, ...) through
the `windows-sys`/`winapi` crates.  Those DLLs are part of Windows and are not
redistributed by this project.  The C runtime is linked statically
(`crt-static`), so no Visual C++ redistributable is required by the shipped
build.
